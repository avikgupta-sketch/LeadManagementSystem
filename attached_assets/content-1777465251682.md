## What is ASP.NET Core?

.NET is a developer platform made up of tools, programming languages, and libraries for building many different types of applications.

ASP.NET Core extends the [.NET developer platform](https://dotnet.microsoft.com/en-US/learn/dotnet/what-is-dotnet) with tools and libraries specifically for building web apps.

[Dig deeper: What is ASP.NET Core?](https://dotnet.microsoft.com/en-us/learn/aspnet/what-is-aspnet-core)

## Fast and scalable

ASP.NET Core performs faster than any popular web framework in the independent [TechEmpower benchmarks](https://www.techempower.com/benchmarks/#hw=ph&test=json).

![In the TechEmpower benchmarks, ASP.NET Core minimal APIs processed 2.05 million JSON responses per second (RPS), Node.js processed 224K, and Java Servlet processed 328K.](https://dotnet.microsoft.com/blob-assets/images/illustrations/tech-empower-results.svg)

Data sourced from official tests available at [TechEmpower Round 23](https://www.techempower.com/benchmarks/#section=data-r23&test=json).

## Build secure apps

ASP.NET Core supports industry standard authentication protocols. Built-in features help protect your apps against cross-site scripting (XSS) and cross-site request forgery (CSRF).

ASP.NET Core provides a built-in user database with support for multi-factor authentication and external authentication with Google, X, and more.
